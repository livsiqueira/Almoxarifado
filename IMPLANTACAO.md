# Pré-requisitos de ambiente (Local)
Para rodar este projeto no seu computador você precita ter instalado:
- [ ] PHP (Versão 8.2 ousuperior);
- [ ] Composer (Gerenciar de pacotes do PHP)
- [ ] Filament (Framework para o laravel)
- [ ] NPM
- [ ] Banco de dados MySQL

# CheckList de Instalação
- [ ] Criar a estrutura da base de Dados no Laravel
- [ ] Instalar o Filament
- [ ] Configurar o arquivo de variáveis de ambiente ('.env).
- [ ] Rodar as Aplicações do banco de dados ('migrations').
